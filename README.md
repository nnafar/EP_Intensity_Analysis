# GUV Intensity Analysis Pipeline

This advanced analysis pipeline is designed to quantify dye uptake kinetics in Giant Unilamellar Vesicles (GUVs) from 2-channel TIFF image stacks. Its primary feature is a robust membrane detection algorithm that uses radial intensity profiling.

The pipeline is intended for experiments (e.g., electroporation) where a dye's intensity inside the GUV is measured over time (on a "Dye" channel, C3) relative to a static membrane-labeled channel (the "ROI" channel, C1).

## Core Methodology

This pipeline's key advantage is its two-stage analysis:

1. **Accurate Masking via Radial Profile Analysis:** Instead of trusting the size parameter from the input CSV, the script analyzes the C1 (ROI) channel. For each GUV, it plots the average signal intensity radiating from the GUV's center. It identifies the peak of this profile as the true membrane, allowing it to define an inner mask (for measurement) and a background mask (for normalization).

2. **Three-Term Normalization:** To correct for background fluorescence and initial dye presence, the pipeline calculates a normalized uptake intensity ($I_{uptake}$) for each GUV using the following formula:

$$I_{uptake} = \frac{(I_{dye,t} - I_{dye,0})}{(I_{background,t} - I_{dye,0})}$$

- $I_{dye,t}$: Intensity inside the GUV at time t.
- $I_{dye,0}$: Baseline intensity inside the GUV before the pulse.
- $I_{background,t}$: Intensity in the local background ring at time t.

This results in a normalized signal that can be averaged across many GUVs and fit to a kinetic model.

## Pipeline Workflow

The pipeline begins by reading GUV coordinates from a `.csv` file. This CSV is expected to be generated by [**DisGUVery**](github.com/DisGUVery/disguvery), which uses template matching to find GUVs in the C1 channel.

This script then takes over to perform the kinetic analysis.

```bash
flowchart TD
    A[Start] --> B(Input: C1/C3 TIF Stacks + C1 CSV from DisGUVery);
    B --> C{For each GUV in CSV};
    C --> D[1. Refine GUV Center];
    D --> E[2. Get C1 Radial Profile];
    E --> F[3. Detect Membrane Peak];
    F --> G[4. Create Masks: Inner & Background];
    G --> H[5. Get C3 Traces: Inner & BG];
    H --> I[6. Detect Pulse Frame];
    I --> C;
    C --> J[End GUV Loop];
    J --> K[7. Normalize All Traces];
    K --> L[8. Align Traces to Median Pulse];
    L --> M[9. Calculate Average Curve];
    M --> N[10. Fit to Model: 4- or 5-Param];
    N --> O(Output: Kinetic Plot, Quality CSV, Debug Images);
    O --> P[End];
```

### Input CSV Format

The input CSV (e.g., `C1-MyExperiment_detected_vesicles.csv`) provides the initial coordinates for GUV detection. It is generated by the DisGUVery software (see Quick User Guide).

The script expects a headerless CSV where the columns are:

1. `id`: A unique identifier for the GUV.

2. `xc`: The x-coordinate of the GUV center.

3. `yc`: The y-coordinate of the GUV center.

4. `size`: The diameter of the GUV (in pixels), used as an *estimate* for detection.

5. `score`: A quality score (not currently used by this pipeline, but must be present).

### How to Use

1. **Generate CSV with DisGUVery:**
   - First, use the DisGUVery software on your C1 (ROI/Membrane) channel to perform template matching.

   - This will generate the `..._detected_vesicles.csv` file.

   - Place this CSV in your main data folder.

2. Install Dependencies:
   ```bash
   pip install -r requirements.txt
   ```
  
3. **Prepare Data:**
   - Ensure your `C1-`, `C3-` `.tif` stacks and the ...`_detected_vesicles.csv` file are all in the same folder.

   - Make sure the file names match the `EXPERIMENT_BASE_NAME` you will set in the config.

4. **Configure the Analysis:**
   - Open `config.py`.
  
   - Set the mandatory file-finding parameters:
  
     - `DATA_FOLDER`: Set this to the absolute path of your data folder (e.g., r"C:\Data\my_data_folder").
  
     - `EXPERIMENT_BASE_NAME`: The common name of your experiment (e.g., "`A1Well4_exp360V`").
  
     - `ROI_CHANNEL_PREFIX`: The prefix for your membrane channel (e.g., "`C1-`").
  
     - `DYE_CHANNEL_PREFIX`: The prefix for your dye channel (e.g., "`C3-`").
  
   - Review other parameters (see Configuration below). Key settings to check are:
     - `MODEL_TO_USE`: '`4-PARAM`' or '`5-PARAM`'.
  
     - `MICRONS_PER_PIXEL`: Set this for an accurate scale bar.
  
     - `EXPORT_MASK_VISUALIZATION`: True is highly recommended for the first run to debug your masks.

5. **Run the Pipeline:**
   ```bash
   python run_analysis.py
   ```

6. **Check Results:**
   - The script will print its progress to the console.

   - All output files will be saved in the output_images folder specified in your `config.py`.

## Configuration (`config.py`)
This file is your main control panel. Key sections:

### ANALYSIS & MASKING PARAMETERS

- `MEMBRANE_SEARCH_FACTOR`: How far (as a %) from the CSV radius estimate to search for the membrane peak.

  - **Tweak**: If your DisGUVery size is very accurate, make this tighter (e.g., 0.2). If the estimate is poor, make this wider (e.g., 0.5).

- `MEMBRANE_FIXED_HALF_WIDTH`: Defines the thickness of the "membrane" region (Peak +/- this value). A value of `3` creates a 6-pixel-wide membrane mask.

- `BG_BUFFER_PIXELS`: The gap (in pixels) between the outer edge of the detected membrane and the start of the background ring.

- `JUMP_SENSITIVITY`: How sensitive the pulse detection is. Higher values are less sensitive (require a bigger intensity jump).

### FITTING & MODELING PARAMETERS

- `MODEL_TO_USE`:

  - `'4-PARAM'`: Exponential rise with linear drift. Good for simple uptake. `I(t) = I_offset + A * (1 - exp(-t/tau)) + D*t`.

  - `'5-PARAM'`: Double exponential rise. Good for complex resealing with two phases. `I(t) = Af - A1*exp(-t/tau1) - A2*exp(-t/tau2)`. 

- `FIT_DATA_PERCENTAGE`: Use this to exclude late-stage data (e.g., photobleaching) from the fit. `0.9` fits the first 90% of the data.

### OUTPUT & VISUALIZATION PARAMETERS

- `OUTPUT_IMAGE_FOLDER`: Where all results are saved.

- `EXPORT_MASK_VISUALIZATION`: If `True`, saves a debug image for the first GUV (and any GUVs with detection warnings) showing the inner (purple), membrane (red), and background (blue) masks.

- `MICRONS_PER_PIXEL`: Used to draw the scale bar on output frames. Set to 0 to disable.

## Explanation of Output Files
Your `output_images` folder will contain:
- `{BASE_NAME}_kinetic_fit.png`: The final summary plot. It shows all individual normalized GUV traces (gray), the average trace (red dots), and the kinetic model fit (black line).

- `{BASE_NAME}_detection_quality.csv`: A log file for quality control. It lists every GUV, its estimated vs. detected radii, and any warnings (e.g., "no_peak_in_window").

- `{BASE_NAME}_mask_viz_GUV_{ID}.png`: A debug image showing the generated masks overlaid on the C1 image. **Use this to verify** your `MEMBRANE_FIXED_HALF_WIDTH` and `BG_BUFFER_PIXELS` are sensible.

- `{BASE_NAME}_radial_profile_GUV_{ID}.png`: The most important debug file. It shows the radial intensity plot for the C1 channel and shades the regions that were defined as "Uptake," "Membrane," and "Background." **Check this file if your results look strange**.

- `frame_{N}_at_{X}s.png`: Styled snapshots from the C3 (Dye) channel at the time points you defined in `EXPORT_TIME_POINTS_S`.
